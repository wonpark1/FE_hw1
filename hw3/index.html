그리드만들기 익숙하지 않은 용어들이라 낯설었음 과제를 하면서 익숙해져야겠다고 느낌

        1.HTML

      • HTML: Hyper Text Markup Language (구조와 의미 부여)
      • 요소(element)와 태그(tag)의 개념
      • 기본 태그: html, head, body, title, h1~h6, p, a, img, ul, ol, li, table, tr, td, th, br, hr

        • 추가

      • lang 속성: 문서의 언어 명시
      • Live Server: 설치하여 HTML 실시간 미리보기

      2.CSS

      • CSS를 통해 HTML에 스타일 적용
      • 작성 방법: 내부 스타일(style 태그), 외부 스타일(link 태그)

          • Flexbox

        • 1차원 레이아웃 시스템 (가로 또는 세로 정렬)
        • flex-direction, justify-content, align-items, align-content, flex-wrap
        • flex-grow, flex-shrink, flex-basis로 크기 조정
        • nth-child(n) 선택자 사용 가능

          Grid

        • 2차원 레이아웃 시스템 (행과 열 모두 제어)
        • grid-template-rows, grid-template-columns, gap, grid-auto-flow
        • grid-template-areas로 영역 이름 지정 가능
